This source is the ACL software package for the MIGU paper. It includes code and scripts for the paper's continual-learning experiments and LoRA/O-LoRA-derived baselines, including the LoRA Replay baseline described in the paper. It is not an official code release for the separate "Combining replay and LoRA" paper.
