# Sequential LoRA Source

No separate official Sequential LoRA source repository was verified. This directory includes a project-local baseline/config view in `source/project_local/` and references the official O-LoRA source at `../o_lora/source` as the closest reproducible continual-learning LoRA base.

See `REPRODUCIBILITY.md` for the baseline constraints: sequential adapter training only, without replay, orthogonal projection, LB-CL knowledge injection, MIGU masking, or other additional continual-learning mechanisms.
