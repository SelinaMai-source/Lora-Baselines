# Replay LoRA Source

No separate official Replay LoRA source repository was verified. This directory includes:

- `source/project_local/`: project-local replay baseline/config view.
- `source/acl_software_unlocking_cl/`: ACL Anthology Software ZIP for "Unlocking Continual Learning Abilities in Language Models", which includes reproducible code for that paper's LoRA Replay baseline.
- `../o_lora/source`: official O-LoRA source used as the closest continual-learning LoRA base.

The ACL ZIP is an ACL software source for the MIGU paper and its LoRA Replay baseline. It must not be described as official code for the separate "Combining replay and LoRA" paper.
