# LB-CL Project-Local Source

No public official LB-CL experiment code was verified. This directory provides the project-local LB-CL scaffold/configs from `/root/autodl-tmp/Lora-code` commit `d711d912926c58c13acc02b3c3e4cfddd9f2c969`. The upstream project README marks this as a scaffold, so it must not be described as a strict official paper implementation unless later verified by the project owner.

Use this scaffold together with `methods/o_lora/source` as the closest reproducible adaptation path. The paper-specific additions are documented in `../../REPRODUCIBILITY.md`: SVD-triplet sensitivity scoring, prior-task knowledge extraction/injection, and O-LoRA-style orthogonal-subspace training.
